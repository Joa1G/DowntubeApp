  DowntubeApp

Downtube é uma aplicação Mobile Hibrida simples e eficiente que permite baixar vídeos do YouTube utilizando apenas o link. A aplicação se comunica com uma API desenvolvida em Python que utiliza o yt-dlp para processar os vídeos e retornar as opções de download.
---
## 🚀 Funcionalidades
- 🔗 Inserção de link do YouTube  
- 📄 Recuperação de informações do vídeo (título, thumbnail, duração, etc.)  
- 🎞️ Listagem de formatos disponíveis para download (vídeo e áudio)  
- 💾 Salvamento em uma pasta do sistema  
- ✅ Tela de confirmação após download concluído
---
## 🛠️ Tecnologias Utilizadas
- **React Native / Expo**
- **TypeScript**
- **Axios** (requisições HTTP)
### Backend (ytdlpAPI)
- **Python**
- **FastAPI**
- **yt-dlp**
- **uvicorn**
